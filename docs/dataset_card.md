# Dataset card (template — complete before a public release)

- **Name / version:** ContactBench transcripts, protocol contact-v0.4, run `RUN_ID`
- **Producer:** fill in the researcher or organization
- **Generated by:** `contact-bench` at code revision `…` (see `manifest.json`)
- **Contents:** public game histories, per-game costs and baselines, paired fixture results, ratings and efficiency
  statistics. Optionally, the post-study omniscient audit (secrets, hidden commitments, seat-private histories).
- **Release policy:** state whether `--include-audit` was used. Players never saw this audit information during play.
- **Lexicon:** name, SHA-256, source and license.
- **Models:** provider, model ID and inference settings for every entry (from `manifest.json → models`).
- **Collection dates:** fill in.
- **Known limitations:** synthetic tasks drawn uniformly from the lexicon; mechanical clue legality only; Monte Carlo
  fallback error (reported); opponent-population dependence of role statistics.
- **Licenses:** code / lexicon / transcripts (check provider terms) / website.
- **Contact:** fill in.
- **Excluded data:** API keys, request headers, private account identifiers, raw stack traces. These are never
  exported, and the exporter scans for credential patterns before writing.
